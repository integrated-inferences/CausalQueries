# Helper to expand nodal expression

Helper to expand nodal expression

## Usage

``` r
expand_nodal_expression(model, query, node, join_by = "|")
```

## Arguments

- model:

  A `causal_model`. A model object generated by
  [`make_model`](https://integrated-inferences.github.io/CausalQueries/reference/make_model.md).

- query:

  A character string. An expression defining nodal types to interrogate.
  An expression of the form "Y\[X=1\]" asks for the value of Y when X is
  set to 1

- node:

  A character string. The quoted name of a node.

- join_by:

  A logical operator. Used to connect causal statements: *AND* ('&') or
  *OR* ('\|'). Defaults to '\|'.

## Value

A nodal expression with no missing parents
