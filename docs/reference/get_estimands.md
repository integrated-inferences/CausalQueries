# helper to get estimands

helper to get estimands

## Usage

``` r
get_estimands(jobs, given_types, query_types, type_posteriors)
```

## Arguments

- jobs:

  a data frame of argument combinations

- given_types:

  output from `queries_to_types`

- query_types:

  output from `queries_to_types`

- type_posteriors:

  output from `get_type_posteriors`

## Value

a list of estimands
