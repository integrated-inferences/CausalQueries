# Produces the possible permutations of a set of nodes

Produces the possible permutations of a set of nodes

## Usage

``` r
perm(max = rep(1, 2))
```

## Arguments

- max:

  A vector of integers. The maximum value of an integer value starting
  at 0. Defaults to 1. The number of permutation is defined by `max`'s
  length

## Value

A `matrix` of permutations
