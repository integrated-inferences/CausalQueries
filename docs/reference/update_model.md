# Fit causal model using 'stan'

Takes a model and data and returns a model object with data attached and
a posterior model

## Usage

``` r
update_model(
  model,
  data = NULL,
  data_type = NULL,
  keep_type_distribution = TRUE,
  keep_event_probabilities = FALSE,
  keep_fit = FALSE,
  censored_types = NULL,
  legacy = NULL,
  ...
)
```

## Arguments

- model:

  A `causal_model`. A model object generated by
  [`make_model`](https://integrated-inferences.github.io/CausalQueries/reference/make_model.md).

- data:

  A `data.frame`. Data of nodes that can take three values: 0, 1, and
  NA. In long form as generated by
  [`make_events`](https://integrated-inferences.github.io/CausalQueries/reference/data_helpers.md)

- data_type:

  Either 'long' (as made by
  [`make_data`](https://integrated-inferences.github.io/CausalQueries/reference/data_helpers.md))
  or 'compact' (as made by
  [`collapse_data`](https://integrated-inferences.github.io/CausalQueries/reference/data_helpers.md)).
  Compact data must have entries for each member of each strategy family
  to produce a valid simplex. When long form data is provided with
  missingness, missing data is assumed to be missing at random.

- keep_type_distribution:

  Logical. Whether to retain `type_posterior`: posterior draws over
  causal types (draws \\\times\\ types). Applies only on the legacy
  (`legacy = TRUE`) path; factorized updates never store
  `type_posterior`. Defaults to `TRUE`.

- keep_event_probabilities:

  Logical. Whether to retain posterior draws of complete-data event
  probabilities `w` (one probability per complete data pattern / column
  of the ambiguity matrix `E`). Accessible after update as
  `posterior_event_probabilities` via
  [`inspect`](https://integrated-inferences.github.io/CausalQueries/reference/inspection.md)
  /
  [`grab`](https://integrated-inferences.github.io/CausalQueries/reference/inspection.md).
  Despite the argument name, this is *not* the coarsened /
  observed-event vector: Stan forms that as `w_full = E * w` for the
  likelihood and does not retain `w_full`. Defaults to `FALSE`.

- keep_fit:

  Logical. Whether to keep the `stanfit` object produced by
  [sampling](https://mc-stan.org/rstan/reference/stanmodel-method-sampling.html)
  for further inspection. See `?stanfit` for more details. Defaults to
  \`FALSE\`. Note the `stanfit` object has internal names for parameters
  (lambda), data type probabilities (w), and the type distribution
  (types)

- censored_types:

  vector of data types that are selected out of the data, e.g.
  `c("X0Y0")`

- legacy:

  Logical or `NULL`. `FALSE` uses the factorized / parameters-only Stan
  model (currently unconfounded models only). `TRUE` uses the
  causal-type Stan path. `NULL` (default) inherits `model$legacy`, then
  `options(CausalQueries.legacy)` (package default `FALSE`).

- ...:

  Options passed onto
  [sampling](https://mc-stan.org/rstan/reference/stanmodel-method-sampling.html)
  call. For details see
  [`?rstan::sampling`](https://mc-stan.org/rstan/reference/stanmodel-method-sampling.html)

## Value

An object of class `causal_model` with posterior distribution on
parameters and other elements generated by updating; all elements
accessible via
[`grab`](https://integrated-inferences.github.io/CausalQueries/reference/inspection.md)
and
[`inspect`](https://integrated-inferences.github.io/CausalQueries/reference/inspection.md).
