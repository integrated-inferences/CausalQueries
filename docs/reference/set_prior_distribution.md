# Add prior distribution draws

Add \`n_param x n_draws\` database of possible parameter draws to the
model.

## Usage

``` r
set_prior_distribution(model, n_draws = 4000)
```

## Arguments

- model:

  A `causal_model`. A model object generated by
  [`make_model`](https://integrated-inferences.github.io/CausalQueries/reference/make_model.md).

- n_draws:

  A scalar. Number of draws.

## Value

An object of class `causal_model` with the \`prior_distribution\`
attached to it.

## See also

Other set:
[`set_confound()`](https://integrated-inferences.github.io/CausalQueries/reference/set_confound.md),
[`set_restrictions()`](https://integrated-inferences.github.io/CausalQueries/reference/set_restrictions.md)

## Examples

``` r
make_model('X -> Y') |>
  set_prior_distribution(n_draws = 5) |>
  inspect("prior_distribution")
#> 
#> prior_distribution
#> Summary statistics of model parameters prior distributions:
#> 
#>   Distributions matrix dimensions are 
#>   5 rows (draws) by 6 cols (parameters)
#> 
#>      mean   sd
#> X.0  0.62 0.22
#> X.1  0.38 0.22
#> Y.00 0.12 0.14
#> Y.10 0.12 0.11
#> Y.01 0.26 0.09
#> Y.11 0.50 0.15
```
