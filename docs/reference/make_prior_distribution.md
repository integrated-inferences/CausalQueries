# Make a prior distribution from priors

Create a \`n_param\`x \`n_draws\` database of possible lambda draws to
be attached to the model.

## Usage

``` r
make_prior_distribution(model, n_draws = 4000)
```

## Arguments

- model:

  A `causal_model`. A model object generated by
  [`make_model`](https://integrated-inferences.github.io/CausalQueries/reference/make_model.md).

- n_draws:

  A scalar. Number of draws.

## Value

A \`data.frame\` with dimension \`n_param\`x \`n_draws\` of possible
lambda draws
