# Helper to turn query into a data expression

Helper to turn query into a data expression

## Usage

``` r
query_to_expression(query)
```

## Arguments

- query:

  A character string. An expression defining nodal types to interrogate.
  An expression of the form "Y\[X=1\]" asks for the value of Y when X is
  set to 1

## Value

A cleaned query expression
